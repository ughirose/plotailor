# Plotailor 開発進捗・課題解決作業レポート（2026-09-26）

## 1. 概要
本レポートは、長編文芸専用執筆統合環境『Plotailor（プロテイラー）』における操作性・安定性課題の解決、および機能分担計画を記録・永続化したものである。

## 2. 本日解決した主要課題と根本原因分析

### ① 日本語IME入力時（Windows MS-IME等）の文字化け・アルファベット残留・重複入力の根絶
- **根本原因**:
  - `cm6ImeGuard.ts` において、`compositionstart` および `compositionupdate`（タイピング中の各キーストローク）ごとに `view.dispatch` を同期呼び出ししていた。
  - CodeMirror 6 の `view.dispatch` は仮想DOMの差分同期（再マウント）を誘発するため、ブラウザが管理する contenteditable 内の未確定文字列ノードが破断・強制コミットされ、MS-IME が「セッションが中断された」と誤認して先頭アルファベットを残存・二重確定させていた。
- **解決策**:
  - 実ブラウザの入力イベント（`event.isTrusted === true`）では `compositionstart` / `compositionupdate` 中の同期 `view.dispatch` をスキップ。
  - CodeMirror 6 ネイティブの `view.composing` に完全委ね、変換確定時（`compositionend`）にのみ状態同期を行うよう改修。
  - 単体テスト（Vitest の合成イベント）互換性を維持し、132件全テストPASS。

### ② ルビ編集の直接操作回帰（ポップアップ/prompt完全廃止）
- **経緯と課題**:
  - 直前の改修で導入された `window.prompt` によるルビ編集ダイアログは操作性が悪く、執筆の没入感を損ねていた。
  - ユーザーは「テキストカーソルを合わせた時だけ該当ルビを直接直せる」方式を求めていた。
- **解決策**:
  - `promptDirectRubyEdit` および `window.prompt` を完全撤去。
  - `expandOnCursor: true` をデフォルト有効化。
  - 平時は美しい `<ruby>` Widget でレンダリングし、**カーソルがそのルビ（親文字〜ルビ範囲）に侵入した時だけ該当ルビ1件のみを青空文庫形式にインライン展開**。カーソルが外れると自動的にリッチルビ Widget に復帰。
  - ルビをクリックした場合もポップアップを出さず、そのルビ位置へカーソルを選択移動させて即座にインライン編集可能とした。

### ③ 章切り替え時の Undo/Redo 履歴混入の完全分離
- **根本原因**:
  - 章切り替え（`loadChapter`）時に `cmEditor.dispatch({ changes: { from: 0, to: len, insert: nextContent } })` で全置換していたため、章ロードが通常の編集履歴としてスタックされ、Ctrl+Z を押すと前の章の内容に巻き戻って混ざる事故が発生していた。
- **解決策**:
  - 各章ごとに独立した `EditorState` を `chapterStates: Map<string, EditorState>` で保持。
  - 章切り替え時は `cmEditor.setState(targetState)` を使用することで、履歴スタック（最大500件）、Selection、スクロール状態を章ごとに完全分離。
  - 独立履歴分離を検証する自動テスト（`tests/vertical-and-history.test.ts`）を追加。

### ④ 自動保存ステータスによるボタン座標揺れの解消 & ステータスバー新設
- **改修内容**:
  - ツールバー上の自動保存テキストの文字数変動によって Undo/Redo ボタンが横揺れしていた問題を解消。
  - 自動保存表示、OPFS AES-GCM-256 暗号化状態、PoP（創作プロセス証明）スコア、文字数・原稿用紙換算を**下部ステータスバー（`ide-footer`）に完全移設・集約**。
  - ツールバーおよびヘッダーのボタンにショートカットキー（`Ctrl+Z` / `Ctrl+Y`）を明記し、ボタン位置を固定化。

### ⑤ 履歴500件一覧ポップアップ & 一括ロールバック機能
- **改修内容**:
  - ツールバーの履歴バッジ（`履歴: X / 500 ▾`）をクリックすると、直近の編集履歴スナップショット（時刻、文字数、プレビュー）を一覧表示するモーダルダイアログを実装。
  - 過去の編集ポイントをクリックするだけで、その時点の本文へ安全にロールバック可能。
