# Plotailor（プロテイラー）
## 思考速度で紡ぐ、次世代長編文芸統合開発環境（IDE）

> **「設定の綻びを恐れるな。あなたの筆跡を、完全ローカル＆AIが守り抜く。」**
> 
> Plotailor は、壮大な世界観の構築から数十万字に及ぶ長編小説の執筆・推敲・設定整合性検査までをシームレスに統合した、プロフェッショナル・クリエイターのための次世代文芸IDEです。

---

## ✦ なぜ Plotailor なのか？

長編小説や世界観創作において、作家は常に「設定の矛盾」「伏線の回収漏れ」「クラウド障害や原稿流出への不安」「AI時代における真正性（人間が書いた証明）の担保」という課題に直面しています。

Plotailor は、プログラミング開発環境（IDE）の思想を文学創作に持ち込み、**完全ローカル環境（OPFS）** と **Wasm極小推論（Narrative-Nano）** を融合することで、かつてない執筆体験を提供します。

---

## ✦ 5大コアフィーチャー

### 1. 3ペイン統合ワークスペース
- **左ペイン［世界観オントロジー］**: 登場人物、舞台、年表、勢力、伏線ツリーを知識グラフとして構造化。
- **中央ペイン［文芸執筆エディタ］**: 思考を遮らないミニマルデザイン。縦書き・横書きの瞬時切替、ルビ・圏点、原稿用紙換算表示に対応。
- **右ペイン［リアルタイム整合性検証 & AIアシスト］**: 本文執筆と同時に設定の矛盾（年齢、時系列、死亡フラグ、呼称の揺れ）をミリ秒単位で検知・警告。

### 2. 完全ローカルファースト（OPFS 採用）
- 原稿・設定データはすべてブラウザの **Origin Private File System (OPFS)** に暗号化保存。
- 外部サーバーへの無断アップロードは一切ありません。オフライン（飛行機内・電波圏外）でも全機能が完全に動作します。
- ネットワーク障害やクラウドサービス停止による原稿消失リスクはゼロです。

### 3. Wasm SIMD 超低遅延推論（Narrative-Nano）
- ブラウザ上で直接動作する極小推論エンジン **Narrative-Nano** を搭載。
- クラウドAPIへの問い合わせ遅延なく、WebAssembly SIMDアクセラレーションにより、キー入力に追従する速度で文脈解析・固有名詞参照・文体検査を実行します。

### 4. 創作プロセス証明（Proof of Process / PoP）
- 1キーストロークごとの編集履歴、推敲差分、執筆タイムスタンプをマークルツリー状の暗号論的ハッシュチェーンで記録。
- 「この作品がAIの一発生成ではなく、作家本人の試行錯誤と推敲の結晶であること」を数学的・客観的に証明する **PoP証明書** をワンクリックで発行可能です。

### 5. 日本語文芸専用エンジニアリング
- 出版基準を満たす高度な縦書きレンダリングエンジン。
- `｜青磁《せいじ》` 等の標準ルビ記法、三点リーダー（……）やダッシュ（――）の禁則処理、文字数／原稿用紙枚数のリアルタイム正確換算を標準装備。

## ✦ よくある質問（FAQ）

**Q. インターネット接続は必要ですか？**  
A. 初期ロードおよびモデルダウンロード完了後は、完全オフラインで動作します。機密性の高い原稿を外部に送信することはありません。

**Q. クラウドストレージ（Google Drive / Dropbox等）との同期は可能ですか？**  
A. 手動または設定によるファイルエクスポート（JSON / Markdown / テキスト形式）に対応しており、お好みのバックアップ先へ保存可能です。

**Q. 大規模な長編（50万字〜100万字超）でも快適に動きますか？**  
A. はい。OPFSによるブロック単位の仮想化読み込みと差分インデックスにより、100万字規模の長編でもメモリ枯渇や入力遅延なく軽快に動作します。

**Q. Proof of Process（PoP）を公開すると原稿のネタバレになりませんか？**  
A. 公開用のPoP証明書は、編集イベントのハッシュ値と統計量（推敲回数、執筆時間推移等）のみを抜粋したゼロ知識証明スタイルのエクスポートが可能です。本文を非公開のまま真正性のみを証明できます。

### 応募・開始手順
1. 配布パッケージ内の `index.html`（またはローカル開発サーバー）をモダンブラウザ（Chrome / Edge / Firefox 最新版推奨）で開きます。
2. 初回起動時のオンボーディングウィザードに従い、Narrative-Nano のローカルWasmキャッシュを初期化します。
3. すぐに新規プロジェクトを作成し、次世代の執筆体験をお試しいただけます。
