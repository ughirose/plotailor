# Plotailor ユーザー操作マニュアル & ヘルプガイド
**Version 0.9.0-preview (Early Access)**

本ガイドでは、次世代文芸統合開発環境 **Plotailor** の基本概念、3ペイン画面の操作方法、キーボードショートカット、ローカルストレージ（OPFS）の仕組み、およびトラブルシューティングについて解説します。

---

## 1. ワークスペース構造（3ペイン画面解説）

Plotailor は「世界観の整合性」と「執筆への没頭」を両立するため、画面を3分割した統合レイアウトを採用しています。

```
+---------------------------------------------------------------------------------------+
|  [ヘッダーバー] プロジェクト名 | 縦横切替 | 統計(文字数/原稿枚数) | エクスポート | 設定 |
+-----------------------+---------------------------------------+-----------------------+
| 【左ペイン】          | 【中央ペイン】                        | 【右ペイン】          |
| 世界観・オントロジー  | 文芸執筆エディタ                      | 整合性検査・PoP・AI   |
|                       |                                       |                       |
| ・キャラクター一覧    | ・原稿執筆エリア                      | ・設定矛盾警告パネル  |
| ・地理・勢力組織      | ・ルビ／圏点入力                      | ・Narrative-Nano推論  |
| ・年代記・時系列      | ・縦書き／横書きモード                | ・伏線ステータス管理  |
| ・伏線構造ツリー      | ・段落インデント・禁則処理            | ・PoP（推敲ハッシュ） |
| ・用語辞典            | ・フォーカスモード（全画面）          | ・バージョン比較      |
+-----------------------+---------------------------------------+-----------------------+
|  [ステータスバー] OPFS保存ステータス: 正常 (同期済) | Wasm SIMD: Active | PoP Block: #1042    |
+---------------------------------------------------------------------------------------+
```

### 左ペイン：設定オントロジー・世界観ツリー
- **エンティティ管理**: キャラクター、場所、組織、アイテム、魔法/科学体系などをツリー＆グラフ構造で登録・編集します。
- **リレーション定義**: 人物間の関係（親族、敵対、主従等）や時間軸ごとのステータス変化（例: 第3章で負傷、第5章で爵位剥奪）を管理します。
- **ドラッグ＆ドロップ参照**: エンティティを中央エディタにドラッグすることで、設定情報を即座にポップアップ参照できます。

### 中央ペイン：文芸執筆エディタ
- **縦書き / 横書き切り替え**: ツールバーのアイコンまたは `Alt + V` でワンタッチ切り替え。日本の出版慣例に則った右送り縦書き表示に対応。
- **ルビ・圏点入力**:
  - ルビ記法: `｜親文字《るび》` または選択後に `Ctrl + R` で入力ダイアログ展開。
  - 傍線・圏点: `《《強調》》` 記法に対応。
- **原稿用紙換算**: 400字詰原稿用紙換算の枚数をリアルタイム表示。行数・文字数設定（例: 40字×40行）もカスタマイズ可能。
- **フォーカスモード（Zen Mode）**: `F11` または `Ctrl + K, Z` で左右ペインを最小化し、執筆に100%集中できます。

### 右ペイン：整合性検査・AIアシスト・PoP履歴
- **リアルタイム整合性アナライザー**:
  - 本文を走査し、左ペインの設定オントロジーと照合。
  - 例: 「第2章時点でまだ合流していないはずのキャラクターが登場している」「瞳の色が設定と異なる」「死亡した人物が発言している」等の不整合を赤・黄のアンダーラインと右パネルで警告。
- **Narrative-Nano（ローカルWasm推論）**:
  - 文脈に沿った表現の類語提案、歴史的用語の言い回しチェック、トーン＆マナー（文体統一）の検証を完全ローカルで即時提案。
- **Proof of Process (PoP) タイムライン**:
  - 編集イベントのブロックハッシュ履歴を表示。推敲の履歴をタイムマシン感覚でロールバック・比較可能。

| :--- | :--- | :--- |

## 3. オフライン保存とデータ永続化（OPFS）

Plotailor は、ウェブブラウザ標準の最新仕様である **Origin Private File System (OPFS)** をプライマリストレージとして使用しています。

### OPFS のメリットと動作原理
1. **完全ローカル**: データはお使いの端末のブラウザサンドボックス内に直接書き込まれます。インターネット接続が切れても一切支障ありません。
2. **高速・大容量**: IndexedDBやLocalStorageと比較して圧倒的なI/Oパフォーマンスを誇り、ギガバイトクラスの原稿や高解像度世界地図画像もストレスなく扱えます。
3. **セキュリティ**: 他のWebサイトや第三者スクリプトからアクセスできない隔離領域に保管されます。

### バックアップとデータ移行
- **プロジェクトの手動エクスポート**:
  - ヘッダー右上の `エクスポート` → `プロジェクト全体アーカイブ (.worldpack)` を選択すると、設定オントロジー・全章本文・PoP証明ハッシュが単一の圧縮ファイルで保存されます。
- **推奨バックアップ運用**:
  - 定期的に `.worldpack` または Markdown 形式でPCのバックアップフォルダや外部ストレージに保存してください。
  - ※ブラウザの「すべての閲覧履歴・サイトデータを削除」を実行するとOPFS領域も消去される場合があるため、執筆の区切りでのプロジェクトエクスポートを推奨します。

## 4. 創作プロセス証明（Proof of Process / PoP）の使い方

### 概要
AI生成テキストの普及に伴い、人間による執筆推敲プロセスの証明が重要視されています。PoPはGitのコミットツリーとブロックチェーンの技術を組み合わせ、執筆の全履歴を暗号学的に改ざん不能な形式で記録します。

### 証明書の発行手順
1. 右ペインの「PoP」タブを選択します。
2. `証明書発行（Generate Certificate）` をクリックします。
3. 発行オプションを選択:
   - **Full Proof**: 推敲履歴の全差分を含む完全版（編集者やコンテスト提出用）。
   - **Zero-Knowledge Proof**: 本文の漏洩を防ぎつつ、「〇時間推敲された」「〇回の変更を経て完成した」という統計ハッシュのみを提示する公開用。
4. 生成された `.pop-cert`（または検証用URL / QRコード）を作家プロフィールやコンテスト応募要項に添付できます。

## 5. トラブルシューティング & FAQ

### Q1. 画面が正しく表示されない / 縦書きが崩れる
- **対処法**:
  - 推奨ブラウザは Google Chrome（最新版）、Microsoft Edge（最新版）です。
  - ブラウザのズーム倍率が極端に変化している場合、`Ctrl + 0` でリセットしてください。
  - ハードウェアアクセラレーションが無効化されている場合、設定で有効にしてください。

### Q2. Narrative-Nano の推論が動作しない
- **対処法**:
  - 右下ステータスバーの `Wasm SIMD` が有効になっているか確認してください。
  - 一部の古いブラウザや環境では WebAssembly SIMD がサポートされていない場合があります。ブラウザのアップデートをご確認ください。

### Q3. 誤ってテキストを消してしまった
- **対処法**:
  - 通常の `Ctrl + Z`（アンドゥ）に加え、右ペインの「PoP履歴」から過去の任意のチェックポイントへロールバックできます。

### Q4. 別PCで続きを執筆したい
- **対処法**:
  - 元PCで `エクスポート` → `.worldpack` を保存し、新PCの Plotailor 画面にドラッグ＆ドロップするだけで、設定や執筆環境を完全に復元できます。
