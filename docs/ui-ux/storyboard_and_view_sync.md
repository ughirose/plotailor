# ストーリーボード・ビュー同期仕様書 (WIF & Storyboard)

## 1. 概要
プロット・シーン構成・タイムライン・本文エディタを相互に同期させるビューメディエータおよび WIF (Worldcraft Interchange Format) エクスポータの仕様。

## 2. 主な機能
- **直交ビュー同期**: エディタのカーソル位置に対応するシーンカード・タイムラインピンを自動追従。
- **ストーリーボード階層**: 幕（Act） -> 章（Chapter） -> シーン（Scene） -> ビート（Beat）のツリー管理。
- **WIF エクスポート**: 世界観オントロジーとプロット構成を内包したポータブルJSON形式の入出力。
