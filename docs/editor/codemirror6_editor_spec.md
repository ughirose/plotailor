# CodeMirror 6 統合文芸エディタ仕様書

## 1. 概要
Plotailor の本文エディタは、CodeMirror 6 をコアとし、日本語長編文芸執筆に特化した拡張群（縦書きレイアウト、ルビ装飾、IME合成同期、およびリアルタイム世界観連携）をネイティブに備える。

## 2. コア機能仕様
1. **縦書き（Vertical Writing）モード**:
   - CSS `writing-mode: vertical-rl` と text-orientation による完全縦書きレンダリング。
   - スクロール方向およびカーソル移動キー（上下左右）の自然なマッピング。
2. **ルビ（Ruby Annotation）デコレーション**:
   - `|漢字《かんじ》` 形式の青空文庫ルビ記法をリアルタイムパース。
   - CM6 StateField / ViewPlugin によるインライン `<ruby>` デコレーション。
3. **IME 入力・変換同期**:
   - 日本語入力時の `compositionstart` / `compositionend` イベントを監視。
   - 変換中の未確定文字列は推論パイプラインへの投入を保留し、確定（Commit）時に差分（delta）としてリングバッファへ送信。
4. **エンティティハイライト & オートコンプリート**:
   - Aho-Corasick 法による高速キーワードマッチング（世界観用語・登場人物名）。
   - ホバーインスペクタによる人物プロファイル・時相状態のプレビュー表示。
