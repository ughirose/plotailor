# SPSC Lock-free Ring Buffer 通信プロトコル仕様書

## 1. 概要
メインスレッド（UI/CodeMirror 6）と Web Worker（推論・構文解析コア）間の高速非同期データ転送を実現する、Single Producer Single Consumer (SPSC) ロックフリーループバッファの仕様。

## 2. メモリ構造とパケット仕様
- **共有メモリ**: 16MB `SharedArrayBuffer`
- **キャッシュライン分離**: 送信ヘッド・受信テールを各 64 バイト境界にアラインメントし、偽共有（False Sharing）を防止。
- **パケットサイズ**: 320 バイト固定
  - ヘッダ: 64 バイト（シーケンス番号、タイムスタンプ、パケット種別、文字オフセット）
  - ペイロード: 255 バイト（UTF-8 差分テキスト）
  - センチネル: 1 バイト（`0xFF`：書き込み完了・整合性確認用フラグ）
- **性能目標**:
  - 送受信レイテンシ: 平均 < 0.5μs
  - パケット欠損率: 0%
  - 60fps タイピング時でも UI スレッドのブロック時間 0ms
