# 05_manuscript_and_creative_writing

## 【文芸執筆・原稿エディタ統合】WorldCraft 小説執筆システム仕様
### 1. 概要と統合の目的
WorldCraftは、設定を管理するだけの外部資料集ではなく、**「世界観オントロジーとリアルタイムに連動する文芸小説執筆IDE」**です。 創作者が本文を執筆しながら、登場人物・地名・年表・伏線をシームレスに参照・検証・反映できる環境を提供します。
### 2. 文芸小説原稿エディタのコア機能（TASK-251〜257）
- 階層型原稿ツリー（章・節・シーン管理）:
  - src/types/manuscript.ts に基づく原稿データモデル。
  - 巻（Volume） > 章（Chapter） > 節（Section） > シーン（Scene）の木構造管理。
  - シーンごとに「発生年代・日時（bound_timeline_event_ids）」「舞台地点（bound_location_pin_ids）」「登場人物（bound_character_ids）」をバインド。
- 日本語文芸組版パーサー & エディタ:
  - 縦書き（右スクロール）／横書きのワンクリック切り替え。
  - ルビ（|漢字《かんじ》）、傍点・圏点（《《強調》》）、ダッシュ・三点リーダーの適正表示。
  - 原稿用紙換算枚数（400字詰）およびリアルタイム文字数カウント。
- 本文内ウィキリンク自動検知 & エンティティホバーインスペクタ:
  - [[Character:char_001|アリシア]] や [[Location:loc_002|王都]] 形式のインラインバインド。
  - キャラクター名や地名にカーソルを合わせると、右詳細ドロワーまたはホバーカードで最新設定（年齢、所属、能力、所持品）がポップアップ。
- 右詳細ドロワー内シーンコンテキスト & 伏線ピン留めタブ:
  - 執筆中のシーンに関連する伏線（Foreshadowing）をインラインでピン留めし、「回収済み」「進行中」「放棄」ステータスを即座に更新。
### 3. 認知フォグ（EpistemicState）トラッカー
「視点人物（POV）がまだ知らないはずの情報を、地の文やセリフでうっかり語ってしまう」という創作者のミスを機械的に防止します。
export interface EpistemicCheckResult {
  character_id: string;
  chapter_id: string;
  scene_scalar_time: number;
  unrevealed_facts_mentioned: Array<{
    fact_id: string;
    keyword: string;
    line_number: number;
    severity: 'warning' | 'info';
    explanation: string; // 例: "アリシアは第3章時点で黒幕の正体を知り得ません"
  }>;
}
- エディタ右側インスペクターに「視点人物の認知状況タブ」を展開し、知っている情報（Known）と知らない情報（Unknown）をリアルタイム表示。
### 4. 出版・商業展開向けエクスポーター（TASK-256）
- EPUB3 電子書籍組版出力:
  - 日本電子書籍出版社協会（EBPAJ）規格に準拠した縦書きCSS、目次階層、ルビ、縦中横（tcy）の完全出力。
- 商業印刷・同人誌即売会向け印刷用PDF出力:
  - 判型（A5、B6、文庫判・新書判）プリセット、断ち落とし（塗り足し3mm）、隠しノンブル、柱（ヘッダー）の自動配置。
- 商業企画書・コミカライズ指示書出力:
  - 世界観バイブル、主要キャラクター相関図、時系列ハイライトをパッケージ化したプロ向けMarkdown/JSON出力。
### 5. 連載原稿一括インジェスト（ディープ・インジェスト・ジョブ）
- 既存の連載原稿（数万〜数十万文字）を一括インポートし、LLMが固有名詞・伏線・時間軸を自動解析。
- 抽出された新規エンティティや伏線を「差分承認UI」で創作者が確認しながら、マニフェストへ一括マージするバッチパイプライン。
